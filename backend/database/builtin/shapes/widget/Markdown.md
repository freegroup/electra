# Markdown

Eine Notiz auf der Fläche, in Markdown geschrieben. Anders als das reine
Text-Widget wird sie gesetzt: Überschriften, Fettschrift, Listen, Links und
Tabellen erscheinen formatiert. Für die Erklärung, die neben eine Schaltung
gehört.

## Parameter

| Name          | Bedeutung              | Voreinstellung                                        |
| :------------ | :--------------------- | :---------------------------------------------------- |
| Markdown Text | der gesetzte Quelltext | *The quick brown fox $ **jumps** over the *lazy* dog* |

## Was zu erwarten ist

- **Keine Anschlüsse, keine Funktion.** Die Notiz nimmt an der Simulation nicht
  teil.
- **Der gesetzte Text liegt als Ebene über der Fläche.** Er folgt dem Kasten beim
  Verschieben, Vergrössern und Zoomen und wird am Rand abgeschnitten - mach den
  Kasten also gross genug.
